# Contributing

Thank you for the interest. Here is how this project works.

## One maintainer

Yare Monster is created and maintained by Orlando Pedro. The official repository does not accept
unsolicited pull requests or code contributions. Keeping one pair of hands on the code keeps it
small, consistent and something a single person can stand behind.

That door is not locked forever. Partners may join over time, but that kind of relationship is
built on trust and real collaboration first, not on a pull request from a stranger. If you think
you could be such a partner, write to the contact in [ATTRIBUTION.md](ATTRIBUTION.md).

Unsolicited pull requests to this repository are closed with a pointer to this page.

## What you can do

- **Run it and adapt your own copy.** The licence lets you modify your copy for personal use and for
  your own business. Your changes live in your copy; they do not need to come back here.
- **Report a bug.** Open an issue with the app name, what you did, what you expected, and what
  happened. Leave out credentials, personal data and anything from your database.
- **Report a security problem privately.** Follow [SECURITY.md](SECURITY.md). Please do not open a
  public issue for it.
- **Ask about commercial use.** If you want to do something the licence does not allow, such as
  offering a paid hosted version, write to the licensing contact in [LICENSE](LICENSE).

## Forks

A public repository can be forked; that is how GitHub works, and the licence does not pretend
otherwise. Forking does not change the official project, and a fork that redistributes the code has
to follow the licence: keep the notices, keep the attribution, do not sell it. Please make clear
that a fork is not an official Yare Monster release.
